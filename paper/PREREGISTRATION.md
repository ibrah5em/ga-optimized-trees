# Pre-Registration

**Written 2026-08-04, before any Phase 1 or Phase 2 re-run.**

The purpose of this document is to fix the decision rules *before* seeing new numbers, so
that a null result is recognised as a null result instead of being re-framed into a
friendlier claim. That failure mode already cost this project a year — see `CLAIMS.md`.

Do not edit this file after the first Phase 3 re-run. Append an outcome section instead.

______________________________________________________________________

## Hypotheses

**H1 (primary).** The NSGA-II-evolved accuracy–complexity frontier dominates, by
hypervolume, the frontier obtained from CART's cost-complexity pruning path
(`ccp_alpha` sweep) on a majority of benchmark datasets.

**H2 (secondary).** Held-out accuracy of the GA's selected operating point is
*equivalent* to inner-CV-tuned CART within a 2% absolute margin, tested by TOST.

**H3 (mechanism).** The GA's frontier advantage over budget-matched random search over
the same tree space is greater than zero.

______________________________________________________________________

## Fixed in advance

| Item                      | Value                                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| Datasets                  | ~20 from OpenML CC-18, selected **before** any run, listed in `paper/DATASETS.md`         |
| Outer evaluation          | 10-fold stratified CV × 3 repeats                                                         |
| Inner tuning              | 5-fold CV, applied identically to every method                                            |
| Equivalence margin (TOST) | **2% absolute accuracy**                                                                  |
| Significance level        | α = 0.05, Holm-corrected across datasets                                                  |
| Frontier metric           | Hypervolume, reference point (accuracy = 0, nodes = max over all methods on that dataset) |
| Primary complexity axis   | **Node count** (not the composite interpretability score)                                 |
| Random-search budget      | Exactly `population_size × n_generations` tree evaluations                                |

## Kill criteria

These are binding.

**K1 — No paper.**
If budget-matched random search matches the GA on hypervolume (difference not
significant, Wilcoxon across datasets, α = 0.05), the evolutionary machinery contributes
nothing. Publish the framework as software (JOSS) and stop.

**K2 — No frontier claim.**
If the GA frontier fails to dominate the `ccp_alpha` frontier on **≥ 60%** of datasets,
H1 is rejected. Do not weaken it to "competitive on some datasets."

**K3 — No equivalence claim.**
If accuracy loss vs inner-CV-tuned CART exceeds the 2% TOST margin on **> 30%** of
datasets, drop "equivalent accuracy" from the paper entirely. Sell controllability of the
operating point, nothing more.

**K4 — No interpretability claim.**
The composite interpretability score is a search heuristic. It may **not** appear as a
reported outcome measure without the human study from Phase 3(b). Reported
interpretability is: #leaves, mean weighted decision-path length, #distinct features.
