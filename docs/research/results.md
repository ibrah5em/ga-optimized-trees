# Detailed Results

> **⚠️ Withdrawn.** This page previously carried per-dataset result tables for iris, wine,
> and breast cancer, including per-fold accuracies, node counts, t-statistics, p-values, and
> Cohen's *d*. All of it has been withdrawn.

None of those tables can be regenerated from the code on `main`, and the parts that could be
checked did not hold up:

- The reported per-fold breakdown was partly elided (`...` rows) and no committed artifact
  backs the full fold-level data.
- Standard deviations were computed with `np.std` at default `ddof=0`, biasing them low.
- The p-values came from a paired t-test across cross-validation folds, which are not
  independent — the test does not apply.
- "No significant accuracy difference" was reported as though it established equivalence. It
  does not, and no equivalence test was run.
- Size reductions were measured against unpruned CART rather than a cost-complexity-pruned
  baseline.

See `paper/CLAIMS.md` for the full audit and `paper/PLAN.md` for the replacement protocol.

## When results return

Every number on this page will be generated by a single reproducible command and committed
alongside the config and the seed that produced it. Per-dataset tables will report, for each
method, held-out accuracy, number of leaves, node count, depth, mean weighted decision-path
length, number of distinct features used, and wall-clock time — with the frontier comparison
(hypervolume against CART's `ccp_alpha` pruning path) as the primary result.

Until then this page stays empty rather than carrying softened versions of the old numbers.
